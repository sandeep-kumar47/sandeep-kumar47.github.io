# Sandeep Kumar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- Accessible navigation with a mobile menu
- Sections for introduction, about, learning skills, projects, and contact
- Custom code-card illustration and project previews built with CSS/HTML
- Reduced-motion preference support
- Dynamic footer year
- No location or personal website URL displayed

## Files

- `index.html` — page structure and content
- `style.css` — layout, visual design, and responsive styling
- `script.js` — mobile navigation and footer year

## GitHub Pages

This repository is named `sandeep-kumar47.github.io`. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**. The site should publish at https://sandeep-kumar47.github.io after deployment completes.

## Run locally

1. Download or clone this repository.
2. Open the `portfolio` folder.
3. Open `index.html` in a browser.

No build tools or package installation are required.

## Customize

Update the text in `index.html` as your skills and projects grow. Add links to real project repositories once they are published. The skills section intentionally describes technologies as learning areas.

## Deploy

The site files are in the root of the dedicated `sandeep-kumar47.github.io` repository for GitHub Pages.
